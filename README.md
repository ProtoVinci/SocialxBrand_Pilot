# SOCIALxBRAND PILOT: website

The motion-led website for **SOCIALxBRAND PILOT**, an Indian digital marketing agency. *We will show, you will grow.*

Built with Next.js 16 (App Router), TypeScript, Tailwind CSS 4, GSAP 3.15 (ScrollTrigger · SplitText · Flip · DrawSVG) and Lenis.

- **Continuing development?** Start with [`HANDOVER.md`](HANDOVER.md), then [`AGENTS.md`](AGENTS.md).
- **Design and motion**: [`docs/`](docs/).

```bash
npm install
npm run dev
npm run build
```
